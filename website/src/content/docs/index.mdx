## Measured results

### Adding streaming JSON iteration to httpx

Six coding agents used `deepseek-flash` for the same [DeepSWE v1.1 task](https://deepswe.datacurve.ai/data/v1.1/tasks/httpx-streaming-json-iteration): add streaming JSON iteration to Python's `httpx` client, handling decoding errors and single-use responses. The model alias is now served by DeepSeek-V4.1-Flash-1017. Time includes model interactions, code changes, and test execution; it excludes environment setup and final cleanup.

| Harness | Time | Estimated cost |
|---------|------|------|
| Chord 0.8.1 | **6m37s** <span class="chord-bar" style="--bar: 30%"></span> | **$0.052** <span class="chord-bar" style="--bar: 32%"></span> |
| deepseek-harness 0.1.5-rc.1 | 9m50s (1.49×) <span class="chord-bar" style="--bar: 44%"></span> | $0.079 (1.51×) <span class="chord-bar" style="--bar: 48%"></span> |
| pi 0.85.1 | 10m22s (1.57×) <span class="chord-bar" style="--bar: 46%"></span> | $0.086 (1.65×) <span class="chord-bar" style="--bar: 52%"></span> |
| codex 0.154.0 | 17m01s (2.57×) <span class="chord-bar" style="--bar: 76%"></span> | $0.139 (2.67×) <span class="chord-bar" style="--bar: 84%"></span> |
| mini-swe-agent 2.4.6 | 18m29s (2.79×) <span class="chord-bar" style="--bar: 82%"></span> | $0.125 (2.40×) <span class="chord-bar" style="--bar: 76%"></span> |
| claude code 2.1.272 | 22m25s (3.39×) <span class="chord-bar" style="--bar: 100%"></span> | $0.166 (3.17×) <span class="chord-bar" style="--bar: 100%"></span> |

Multipliers are relative to Chord. Chord was fastest and cheapest, and used the fewest input and output tokens (54,530 / 58,559).

Chord trims old tool output when building each request, compacts long-session context, and starts safe tools as soon as their arguments are complete; see [Performance](/chord/performance/#how-it-works) for details.

### App memory

Memory measured on macOS 15.3.2 (arm64), with an empty session and after loading 200 messages:

| Harness | Empty session | 200 messages | Growth |
|---------|---------------|--------------|--------|
| Chord 0.8.1 | 30MB | **39MB** | **+9MB** |
| codex 0.154.0 | **27MB** | 47MB | +20MB |
| claude code 2.1.273 | 143MB | 216MB | +73MB |

One measured task and one memory test; your numbers will differ. [See the token breakdown and test conditions](/chord/performance/#measured-results).

## Three-step setup

<CardGrid>
  <Card title="1. Install" icon="download">
    Download the archive for your OS and architecture from [GitHub Releases](https://github.com/keakon/chord/releases), extract it, and put `chord` on your `PATH`. No Go installation is needed.

    You can also install with Go 1.27.0 or newer:

    ```bash
    go install github.com/keakon/chord/cmd/chord@latest
    ```

    On macOS, the downloaded binary may be blocked on first run; see [Quickstart](/chord/quickstart/#1-install) for the steps to unblock it.
  </Card>
  <Card title="2. Run from your project" icon="window">
    ```bash
    cd my-project
    chord
    ```
    On the first run without a configuration file, the wizard guides you through entering your model API URL, model name, and API key, or signing in with Codex OAuth.
  </Card>
  <Card title="3. Send your first task" icon="pencil">
    Type a task and press `Enter`:

    ```text
    Explain this project's main modules and how to run its tests. Do not change any files yet.
    ```

    Press `Esc` from the composer to enter Normal mode and browse the reply and tool cards. For a coding task, review changes in the terminal as Chord works. Default permissions allow edits and commands directly; deletions governed by the `delete` rule require confirmation. To configure approval before execution, see [Permissions & Safety](/chord/permissions-and-safety/).
  </Card>
</CardGrid>

Supported on macOS, Linux, and Windows (including WSL); a few system-level features are platform-specific. See [Platform support](/chord/platforms/).

## More features

- [Automatic model fallback](/chord/configuration/#model-pools-selecting-providermodel): configure multiple models so Chord can automatically try the next model when a request fails.
- [Import existing sessions](/chord/usage/#importing-external-sessions): bring your Claude Code, Codex, or OpenCode history into Chord and continue working.
- [Vim-style keyboard controls](/chord/keybindings/): browse sessions, operate tool cards, and switch panels from the keyboard.
