## Three-step setup

<CardGrid>
  <Card title="1. Install" icon="download">
    Prebuilt binaries do not require Go. If you already have Go 1.27.0+ installed:

    ```bash
    go install github.com/keakon/chord/cmd/chord@latest
    ```

    If not, download a prebuilt binary from [GitHub Releases](https://github.com/keakon/chord/releases), extract it, and put `chord` on your `PATH`.
  </Card>
  <Card title="2. Run setup once" icon="pen">
    Run `chord` in an interactive terminal:

    ```bash
    chord
    ```

    If `config.yaml` is missing, Chord launches a one-time setup wizard. The wizard creates the minimal `config.yaml` and, when needed, `auth.yaml`.

    Prefer to write YAML manually or need a different provider/model setup? See [Quickstart](/chord/quickstart/).
  </Card>
  <Card title="3. Run from your project" icon="window">
    ```bash
    cd my-project
    chord
    ```
    On first run in a project, Chord creates `.chord/` as needed.
  </Card>
</CardGrid>

## What else Chord does

- Keyboard-first, Vim-style keybindings
- Notifies you only when you're needed
- Hot-swap model pools without restarting
- Remote control through `chord headless`
- Session import from Claude Code, Codex, and OpenCode
- LSP integration
- Image preview in the terminal
- Codex subscription quota and reset time
- Customizable agent teams
- Parallel work via git worktrees
