## Three-step setup

<CardGrid>
  <Card title="1. Install" icon="download">
    Install with Homebrew (macOS and Linux):

    ```bash
    brew install keakon/tap/chord
    ```

    You can also download the archive from [GitHub Releases](https://github.com/keakon/chord/releases), or install with Go 1.27.0 or newer:

    ```bash
    go install github.com/keakon/chord/cmd/chord@latest
    ```

    See [Quickstart](/chord/quickstart/#1-install) for details.
  </Card>
  <Card title="2. Run from your project" icon="window">
    ```bash
    cd my-project
    chord
    ```
    On the first run, the wizard guides you through model setup: enter an API URL, model name, and API key, or sign in with Codex OAuth. See [Model access](/chord/model-choice/#supported-accounts-and-apis) for supported accounts and APIs.
  </Card>
  <Card title="3. Send your first task" icon="pencil">
    Type a task and press `Enter`:

    ```text
    Explain this project's main modules and how to run its tests. Do not change any files yet.
    ```

    Default permissions allow edits and commands directly; to approve actions first, see [Permissions & Safety](/chord/permissions-and-safety/).
  </Card>
</CardGrid>

Supported on macOS, Linux, and Windows (including WSL); a few system-level features are platform-specific. See [Platform support](/chord/platforms/).

## Measured comparison

Six coding agents completed the same [DeepSWE v1.1 task](https://deepswe.datacurve.ai/data/v1.1/tasks/httpx-streaming-json-iteration) with the same model (`deepseek-flash`). Chord was fastest and cheapest:

| Harness | Time | Estimated cost |
|---------|------|------|
| Chord 0.8.1 | **6m37s** <span class="chord-bar" style="--bar: 30%"></span> | **$0.052** <span class="chord-bar" style="--bar: 32%"></span> |
| deepseek-harness 0.1.5-rc.1 | 9m50s (1.49×) <span class="chord-bar" style="--bar: 44%"></span> | $0.079 (1.51×) <span class="chord-bar" style="--bar: 48%"></span> |
| pi 0.85.1 | 10m22s (1.57×) <span class="chord-bar" style="--bar: 46%"></span> | $0.086 (1.65×) <span class="chord-bar" style="--bar: 52%"></span> |
| codex 0.154.0 | 17m01s (2.57×) <span class="chord-bar" style="--bar: 76%"></span> | $0.139 (2.67×) <span class="chord-bar" style="--bar: 84%"></span> |
| mini-swe-agent 2.4.6 | 18m29s (2.79×) <span class="chord-bar" style="--bar: 82%"></span> | $0.125 (2.40×) <span class="chord-bar" style="--bar: 76%"></span> |
| claude code 2.1.272 | 22m25s (3.39×) <span class="chord-bar" style="--bar: 100%"></span> | $0.166 (3.17×) <span class="chord-bar" style="--bar: 100%"></span> |

After loading 200 messages, Chord uses just 39MB of memory (Claude Code: 216MB). See [Performance](/chord/performance/#measured-results) for token breakdowns and test conditions.
