## Feature highlights

<ul className="chord-highlights">
  <li>
    <a href="/chord/configuration/#model-pools-selecting-providermodel">Automatic model fallback</a>
    <span class="chord-why">A failing key or model does not stop the session.</span>
  </li>
  <li>
    <a href="/chord/context-management/">Request trimming plus compaction</a>
    <span class="chord-why">Long sessions stay inside the context window and spend fewer tokens.</span>
  </li>
  <li>
    <a href="/chord/performance/#streaming-tool-early-execution">Streaming tool early execution</a>
    <span class="chord-why">Safe tools start before the model finishes its response.</span>
  </li>
  <li>
    <a href="/chord/performance/#app-memory">Small memory footprint</a>
    <span class="chord-why">30MB empty and 39MB after 200 messages in the measured scenario.</span>
  </li>
  <li>
    <a href="/chord/usage/#importing-external-sessions">Import Claude Code, Codex, and OpenCode sessions</a>
    <span class="chord-why">Keep your history when you switch tools.</span>
  </li>
  <li>
    <a href="/chord/keybindings/">Vim-style keyboard controls</a>
    <span class="chord-why">Stay in the terminal flow without reaching for the mouse.</span>
  </li>
</ul>

## Measured results

Six agent harnesses ran the same [DeepSWE v1.1 task](https://deepswe.datacurve.ai/data/v1.1/tasks/httpx-streaming-json-iteration): adding streaming JSON iteration to `httpx`. All six runs used deepseek-v4.1-flash. Chord 0.8.1 finished first and cheapest, with the next-best run taking 1.49× as long and costing 1.51× as much.

## Three-step setup

<CardGrid>
  <Card title="1. Install" icon="download">
    **With Go 1.27.0 or newer**:

    ```bash
    go install github.com/keakon/chord/cmd/chord@latest
    ```

    **Without Go**: download a prebuilt binary from [GitHub Releases](https://github.com/keakon/chord/releases), extract it, and put `chord` on your `PATH`.
  </Card>
  <Card title="2. Run from your project" icon="window">
    ```bash
    cd my-project
    chord
    ```
    On the first run, if no `config.yaml` is found, Chord starts the setup wizard.
  </Card>
  <Card title="3. Send your first task" icon="pencil">
    Describe what you want and press `Enter`. Start by asking Chord to read the project:

    ```text
    Explain this project's main modules and how to run its tests. Do not change any files yet.
    ```
  </Card>
</CardGrid>

Supported on macOS, Linux, and Windows (including WSL); a few system-level features are platform-specific. See [Platform support](/chord/platforms/).
