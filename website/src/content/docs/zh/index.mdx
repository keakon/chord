## 三步上手

<CardGrid>
  <Card title="1. 安装" icon="download">
    下载预构建二进制不需要安装 Go。已安装 Go 1.27.0+ 时，也可以直接用源码安装：

    ```bash
    go install github.com/keakon/chord/cmd/chord@latest
    ```

    未安装 Go 1.27.0+ 时，可从 [GitHub Releases](https://github.com/keakon/chord/releases) 下载预构建二进制，解压后把 `chord` 放到 `PATH` 中。
  </Card>
  <Card title="2. 先运行一次初始化向导" icon="pen">
    在交互式终端里直接运行：

    ```bash
    chord
    ```

    如果缺少 `config.yaml`，Chord 会启动一次性的初始化向导。向导会创建最小可用的 `config.yaml`，必要时再创建 `auth.yaml`。

    如果你更希望手写 YAML，或需要不同的 provider / 模型配置，见[快速开始](/chord/zh/quickstart/)。
  </Card>
  <Card title="3. 在项目里启动" icon="window">
    ```bash
    cd my-project
    chord
    ```
    在某个项目中首次运行时，Chord 会按需创建 `.chord/`。
  </Card>
</CardGrid>

## 其他能力

- 键盘优先，Vim 风格
- 需要你处理时才通知
- 模型池热切换，无需重启
- 通过 `chord headless` 远程操控
- 导入 Claude Code、Codex、OpenCode 的会话
- LSP 集成
- 终端内预览图片
- 显示 Codex 订阅额度与重置时间
- 可自定义的 Agent 团队
- 基于 git worktree 的并行任务
