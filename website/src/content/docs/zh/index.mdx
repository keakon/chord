## 三步上手

<CardGrid>
  <Card title="1. 安装" icon="download">
    下载预构建二进制不需要安装 Go。已安装 Go 1.27.0+ 时，也可以直接用源码安装：

    ```bash
    go install github.com/keakon/chord/cmd/chord@latest
    ```

    未安装 Go 1.27.0+ 时，可从 [GitHub Releases](https://github.com/keakon/chord/releases) 下载预构建二进制，解压后把 `chord` 放到 `PATH` 中。
  </Card>
  <Card title="2. 先运行一次初始化向导" icon="pen">
    在交互式终端里直接运行：

    ```bash
    chord
    ```

    如果缺少 `config.yaml`，Chord 会启动一次性的初始化向导。向导会创建最小可用的 `config.yaml`，必要时再创建 `auth.yaml`。

    如果你更希望手写 YAML，或需要不同的 provider / 模型配置，见[快速开始](/chord/zh/quickstart/)。
  </Card>
  <Card title="3. 在项目里启动" icon="window">
    ```bash
    cd my-project
    chord
    ```
    在某个项目中首次运行时，Chord 会按需创建 `.chord/`。
  </Card>
</CardGrid>

## 为什么选 Chord

<CardGrid>
  <Card title="长会话更省上下文" icon="database">
    请求时剪裁陈旧工具输出，并用类型化摘要保留大块结果的关键信息；接近上限前再压缩早期内容。
  </Card>
  <Card title="轻量常驻" icon="approve-check-circle">
    近乎瞬间加载上千条消息的历史会话，退出无需等待；内存占用低，空闲数分钟后卸载 LSP/MCP 资源。
  </Card>
  <Card title="网络状态全程可见" icon="analytics">
    模型调用过程中精确显示请求状态与已等待时间，再也不用猜「是不是卡住了」。
  </Card>
  <Card title="模型组合热切换" icon="random">
    将模型分到可复用的池（`fast`、`thinking`、`cheap`），运行时用 `/models` 或 `Ctrl+P` 切换。运行时按池内顺序自动 fallback。
  </Card>
</CardGrid>

## 更多能力

<CardGrid>
  <Card title="键盘优先、Vim 风格" icon="vim">
    面向习惯全键盘操作的用户：Insert / Normal 模式、Vim 风格导航、消息搜索，模式切换时自动切输入法。
  </Card>
  <Card title="项目上下文" icon="magnifier">
    LSP 诊断、definition/reference/implementation 查询、Git 状态，以及
    `@` 文件补全。
  </Card>
  <Card title="图片和 PDF 输入" icon="document">
    粘贴图片，按模型能力附加图片或 PDF；支持的终端可预览图片，模型也可用 `view_image` 查看本地 PNG/JPEG。
  </Card>
  <Card title="多 Agent 协作" icon="comment">
    主 Agent 搭配职责聚焦的 SubAgent，各自独立上下文，用 `Shift+Tab` 切换。
  </Card>
  <Card title="worktree 并行开发" icon="code-branch">
    `chord --worktree feat-auth` 会创建隔离的工作副本，同一仓库上的多个任务互不干扰。
  </Card>
  <Card title="导入外部会话" icon="cloud-download">
    可把 Claude Code、Codex、OpenCode 会话迁移成可恢复的 Chord 会话。
  </Card>
</CardGrid>

## 性能实测

在一个真实的 Pebble 数据库任务上，Chord 比 Codex-CLI **快 24%**，输入 token **少 63%**，成本**低 63%**。应用本身启动和退出都在 **1 秒内**，空会话内存 **31.6MB**。

这些是特定场景下的依据，不是对所有任务的通用承诺。完整数据表、测量方法和适用范围见[性能 — 实测数据](/chord/zh/performance/#实测数据)。
