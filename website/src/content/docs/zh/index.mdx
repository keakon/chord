## 实测数据

### 给 httpx 添加流式 JSON 迭代接口

六款编程 Agent 用同一个模型分别完成同一个 [DeepSWE v1.1 任务](https://deepswe.datacurve.ai/data/v1.1/tasks/httpx-streaming-json-iteration)：给 Python HTTP 客户端 `httpx` 添加流式 JSON 迭代接口，并处理解码失败、响应重复迭代等边界情况。模型均为 `deepseek-flash`（现由 DeepSeek-V4.1-Flash-1017 提供服务）。耗时包含模型交互、代码修改和测试执行，不含环境准备和最终收尾。

| 工具 | 耗时 | 估算成本 |
|---------|------|------|
| Chord 0.8.1 | **6m37s** <span class="chord-bar" style="--bar: 30%"></span> | **￥0.348** <span class="chord-bar" style="--bar: 32%"></span> |
| deepseek-harness 0.1.5-rc.1 | 9m50s（1.49 倍） <span class="chord-bar" style="--bar: 44%"></span> | ￥0.527（1.51 倍） <span class="chord-bar" style="--bar: 48%"></span> |
| pi 0.85.1 | 10m22s（1.57 倍） <span class="chord-bar" style="--bar: 46%"></span> | ￥0.576（1.65 倍） <span class="chord-bar" style="--bar: 52%"></span> |
| codex 0.154.0 | 17m01s（2.57 倍） <span class="chord-bar" style="--bar: 76%"></span> | ￥0.929（2.67 倍） <span class="chord-bar" style="--bar: 84%"></span> |
| mini-swe-agent 2.4.6 | 18m29s（2.79 倍） <span class="chord-bar" style="--bar: 82%"></span> | ￥0.835（2.40 倍） <span class="chord-bar" style="--bar: 76%"></span> |
| claude code 2.1.272 | 22m25s（3.39 倍） <span class="chord-bar" style="--bar: 100%"></span> | ￥1.104（3.17 倍） <span class="chord-bar" style="--bar: 100%"></span> |

括号内为相对 Chord 的倍数。Chord 用时最短、成本最低，输入和输出 token（54,530 / 58,559）也最少。

Chord 会在每次请求前剪裁旧工具输出、对长会话做持久压缩，并在参数完整时提前执行安全工具；实现细节见[性能](/chord/zh/performance/#工作方式)。

### 应用内存

在 macOS 15.3.2（arm64）上，分别测量空会话和加载 200 条消息后的内存占用：

| 工具 | 空会话 | 200 条消息 | 增量 |
|---------|--------|------------|------|
| Chord 0.8.1 | 30MB | **39MB** | **+9MB** |
| codex 0.154.0 | **27MB** | 47MB | +20MB |
| claude code 2.1.273 | 143MB | 216MB | +73MB |

以上数据来自一次任务实测和一次内存测试，不代表普遍结果。[查看 token 明细与测量条件](/chord/zh/performance/#实测数据)。

## 三步上手

<CardGrid>
  <Card title="1. 安装" icon="download">
    从 [GitHub Releases](https://github.com/keakon/chord/releases) 下载对应系统和架构的压缩包，解压后把 `chord` 加入 `PATH`，不需要安装 Go。

    也可用 Go 1.27.0 或更新版本安装：

    ```bash
    go install github.com/keakon/chord/cmd/chord@latest
    ```

    macOS 下载版首次运行可能被系统阻止，处理步骤见[快速开始](/chord/zh/quickstart/#1-安装)。
  </Card>
  <Card title="2. 在项目里启动" icon="window">
    ```bash
    cd my-project
    chord
    ```
    首次运行且没有配置文件时，向导会引导你填写模型 API 地址、模型名称和 API key，或通过 Codex OAuth 登录。
  </Card>
  <Card title="3. 发送第一个任务" icon="pencil">
    直接描述你想让它做什么，按 `Enter` 发送。第一次可以先让它读一遍项目：

    ```text
    请解释这个项目的主要模块和测试入口，先不要修改文件。
    ```

    先看它的回答。默认配置下，Chord 会直接修改文件和执行命令，只有用 `delete` 工具删除文件时需要确认；想先审批再执行，见[权限与安全](/chord/zh/permissions-and-safety/)。熟悉项目后，交给它一个具体改动：它负责改代码、跑测试，你在终端里检查 diff。
  </Card>
</CardGrid>

支持 macOS、Linux、Windows（含 WSL），少数系统级能力只在部分平台生效，见[平台支持](/chord/zh/platforms/)。

## 更多功能

- [模型自动切换](/chord/zh/configuration/#模型池)：配置多个模型，请求失败时自动尝试切换到下一个模型并重试。
- [导入已有会话](/chord/zh/usage/#导入外部会话)：导入 Claude Code、Codex 或 OpenCode 的会话历史，在 Chord 中继续工作。
- [Vim 风格键盘操作](/chord/zh/keybindings/)：用键盘浏览会话、操作工具卡和切换面板。
