## 实测数据

六款同类编码 agent 用同一个模型（deepseek-v4.1-flash）跑同一个 [DeepSWE v1.1 任务](https://deepswe.datacurve.ai/data/v1.1/tasks/httpx-streaming-json-iteration)：给 `httpx` 加上流式 JSON 迭代接口。Chord 0.8.1 用时最短、成本最低，第二名的耗时是它的 1.49 倍、成本是 1.51 倍。

### 应用内存

测试环境：macOS 15.3.2（arm64）。

| 工具 | 空会话 | 200 条消息 | 增量 |
|---------|--------|------------|------|
| Chord 0.8.1 | 30MB | **39MB** | **+9MB** |
| codex 0.154.0 | **27MB** | 47MB | +20MB |
| claude code 2.1.273 | 143MB | 216MB | +73MB |

以上数据来自一次任务实测和一次内存场景，不代表普遍结果。完整数据表、测量方法和实现说明见[性能](/chord/zh/performance/#实测数据)。

## 三步上手

<CardGrid>
  <Card title="1. 安装" icon="download">
    **已安装 Go 1.27.0+**：直接用源码安装：

    ```bash
    go install github.com/keakon/chord/cmd/chord@latest
    ```

    **未安装 Go 1.27.0+**：从 [GitHub Releases](https://github.com/keakon/chord/releases) 下载预构建二进制，解压后把 `chord` 放到 `PATH` 中。
  </Card>
  <Card title="2. 在项目里启动" icon="window">
    ```bash
    cd my-project
    chord
    ```
    第一次运行时，如果未检测到 `config.yaml`，会启动初始化向导。然后直接描述第一个任务，按 `Enter` 发送。
  </Card>
  <Card title="3. 发送第一个任务" icon="pencil">
    直接描述你想让它做什么，按 `Enter` 发送。第一次可以先让它读一遍项目：

    ```text
    请解释这个项目的主要模块和测试入口，先不要修改文件。
    ```
  </Card>
</CardGrid>

支持 macOS、Linux、Windows（含 WSL），少数系统级能力只在部分平台生效，见[平台支持](/chord/zh/platforms/)。
