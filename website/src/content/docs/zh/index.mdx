## 三步上手

<div class="chord-steps">
<CardGrid>
  <Card title="1. 安装" icon="download">
    macOS 和 Linux：

    ```bash
    brew install keakon/tap/chord
    ```

    Windows 从 [GitHub Releases](https://github.com/keakon/chord/releases) 下载压缩包，解压后把 `chord` 加入 `PATH`。
  </Card>
  <Card title="2. 在项目里启动" icon="window">
    ```bash
    cd my-project
    chord
    ```

    首次运行会进入向导：填写 API 地址、模型名称和 API key，或用 Codex 账号登录。
  </Card>
  <Card title="3. 发送第一个任务" icon="pencil">
    输入任务，按 `Enter` 发送：

    ```text
    请解释这个项目的主要模块和测试入口，先不要修改文件。
    ```

    Chord 默认会直接修改文件和执行命令；使用 `delete` 删除文件，或通过 `apply_patch` 删除、移动文件时，需要确认。
  </Card>
</CardGrid>
</div>

其他安装方式、升级和首次配置的完整步骤见[快速开始](/chord/zh/quickstart/)。

## 为什么选 Chord

<CardGrid>
  <Card title="多 Agent 并行" icon="random">
    [定义子 Agent 角色并授予主 Agent 委派权限](/chord/zh/configuration/#agent-配置)后，主 Agent 可把子任务交给子 Agent 并行处理，按 `Shift+Tab` 切换查看每个 Agent 的进度和上下文。
  </Card>
  <Card title="模型自动切换" icon="setting">
    用模型池组合多个服务商和模型，请求失败时自动换下一个；同一服务商可以配多个 key 轮换。
  </Card>
  <Card title="长会话不爆上下文" icon="list-format">
    每次请求前自动剪掉旧的大块工具输出；上下文接近上限时压缩成摘要，原文归档备查。
  </Card>
  <Card title="执行前可审批" icon="approve-check">
    按工具和命令设置 allow / ask / deny 规则，高风险操作先确认再执行。
  </Card>
</CardGrid>

### 实测对比

六款编程 Agent 用同一模型（`deepseek-flash`）完成同一 [DeepSWE v1.1 任务](https://deepswe.datacurve.ai/data/v1.1/tasks/httpx-streaming-json-iteration)，Chord 用时最短、成本最低：

| 工具 | 耗时 | 估算成本 |
|---------|------|------|
| Chord 0.8.1 | **6m37s** <span class="chord-bar" style="--bar: 30%"></span> | **￥0.348** <span class="chord-bar" style="--bar: 32%"></span> |
| deepseek-harness 0.1.5-rc.1 | 9m50s（1.49 倍） <span class="chord-bar" style="--bar: 44%"></span> | ￥0.527（1.51 倍） <span class="chord-bar" style="--bar: 48%"></span> |
| pi 0.85.1 | 10m22s（1.57 倍） <span class="chord-bar" style="--bar: 46%"></span> | ￥0.576（1.65 倍） <span class="chord-bar" style="--bar: 52%"></span> |
| codex 0.154.0 | 17m01s（2.57 倍） <span class="chord-bar" style="--bar: 76%"></span> | ￥0.929（2.67 倍） <span class="chord-bar" style="--bar: 84%"></span> |
| mini-swe-agent 2.4.6 | 18m29s（2.79 倍） <span class="chord-bar" style="--bar: 82%"></span> | ￥0.835（2.40 倍） <span class="chord-bar" style="--bar: 76%"></span> |
| claude code 2.1.272 | 22m25s（3.39 倍） <span class="chord-bar" style="--bar: 100%"></span> | ￥1.104（3.17 倍） <span class="chord-bar" style="--bar: 100%"></span> |

内存方面，加载 200 条消息后 Chord 仅占 39MB（Claude Code: 216MB）。完整测量条件见[性能](/chord/zh/performance/#实测数据)。
